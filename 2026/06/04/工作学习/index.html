Linux服务器

加bash运行脚本和不加有什么区别

运行方式 需要执行权限 尊重 shebang 实际解释器 是否子 Shell 典型场景
bash script.sh ❌（只需读） ❌，强制用 bash bash ✅ 是 快速测试，或强制使用 bash 特性
./script.sh ✅ 必须 ✅，按 shebang 选择 由 shebang 决定（可能为 sh/dash/bash 等） ✅ 是 正式部署，脚本自解释、可移植
source script.sh 或 . script.sh ❌（只需读） ❌，在当前 Shell 执行 当前 Shell（如 bash） ❌ 否 加载环境变量、函数，修改当前 Shell 状态
