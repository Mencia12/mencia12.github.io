TAE笔记

发表于 2026-07-14 更新于 2026-07-22

记账引擎笔记

  • Java interface：

    • 28 个业务/RPC 契约：17 个
    • MapStruct/对象转换接口：11 个（不属于需要优先理解的业务接口）

  • HTTP 管理接口：5 个，全部在 TaeMainManagementController

  • 联机核心对外契约：6 个接口、20 个方法声明

    • ITaeService：10 个统一入口方法
    • ICheckCompensation、ISettleEngine、ISettleReversal、 ITaeAcctCollate、ITccSettleEngine：10 个细分服务方法

其中存在同一业务能力的聚合/细分声明，不能简单视为 20 个互不重复的业务功能。

  1. 建立领域模型主交易、子交易、交易场景、补偿、对账、进度状态。
    重点 repository 下的 TaeAcctMaintradesPo、TaeAcctSubtradesPo、TaeAcctScencePo、TaeCompensationPo。

  2. 掌握联机入口与业务语义
    从 online/api/rpc/ITaeService 开始：同步记账、订单记账、异步记账、TCC、冲正、结果回写、补偿、对账文件。
    再看五个细分接口，了解每种能力的入参与返回 DTO。

  3. 沿流程读实现，而不是先读全部代码
    核心流程：TaeOrderEngineFlow、TaeSettleEngineFlow、TaeOrderReversalFlow、TaeCompensationFlow、TaeAcctCollateQueryFlow。
    关键编排组件：TaeOrderEngineComponent、TaeSettleEngineComponent、TaeSettleReversalComponent。
    关键执行单元：TaeTradeUnit、TaeReversalUnit、TaeTimeOutUnit、TaeTransitIsolationUnit。

  4. 理解外围系统适配
    integration-common 定义记账、冲正、校验、隔离资金、TCC 的统一抽象。
    再按实际业务系统学习 rb（存款）、cl（贷款）、tb（运营）适配实现；其中 ITaeCallRbService 方法最多，是集成复杂度最高的一侧。

  5. 运行与运维能力
    server-service：联机部署。
    server-batch：批量补偿、自动记账/冲正、对账文件。
    server-manager：5 个管理查询/更新 HTTP 接口。
    server-all：全量部署形态。

TaeSettleEngineFlow

方法
功能描述
 输入(Input) 内部操作 输出(Output)
TaeSettleEngineFlow 执行TAE普通记账流程，根据交易场景选择简化记账或标准记账处理 SettleEngineIn接口层交易请求对象，包含交易信息、账户子流水等 通过 SettleEngineInConvert.INSTANCE.to(in) 将接口对象转换为 SettleEngineInput；遍历 TaeAcctSubtradesRow 判断交易账户系统是否一致；通过 TaeCommonConfiguration.getTransactionMode() 判断事务模式；满足数据库事务模式且账户系统一致时调用 TaeSettleEngineSimplifiedComponent.execute() 执行简化记账，否则调用 TaeSettleEngineComponent.execute() 执行标准记账；最后通过 SettleEngineOutConvert.INSTANCE.to() 转换返回结果 SettleEngineOut记账结果对象，包含交易处理结果、流水信息等

TaeSettleEngineSimplifiedComponent

方法
功能描述
 输入(Input) 内部操作 输出(Output)
TaeSettleEngineSimplifiedComponent 执行数据库事务模式下的记账流程，完成主子流水初始化、账户记账、交易结果更新及流水落库 SettleEngineInput业务层记账请求对象，包含主交易信息、账户子交易信息 初始化 TaeAcctMaintradesPo、TaeAcctSubtradesPo、TaeAcctSubtradesAttachmentPo、TaeTranInfoPo 等流水对象；调用 TaeSettleEngineUnit.preProcess() 完成幂等检查和流水模型settleEngineOutput初始化；若settleEngineOutput为空，则按照借方优先顺序调用 chargeAccount() 执行账户记账；更新主流水、交易状态及返回结果；调用 TaeTradeUnit.insertTeaAcctTrades() 保存TAE交易流水 SettleEngineOutput返回记账结果，包括交易状态、响应码、子流水处理明细

chargeAccount

方法
功能描述
 输入(Input) 内部操作 输出(Output)
chargeAccount 循环处理账户子流水，调用具体账户系统完成记账，并记录处理结果 TaeAcctMaintradesPo 主流水List<TaeAcctSubtradesPo> 子流水集合Map<String,TaeAcctSubtradesAttachmentPo> 扩展信息List<SubResultDetail> 结果明细 遍历 TaeAcctSubtradesPo；根据 acctSystem 调用 TaeIntegrationFactory.sageInstance() 获取对应账户系统处理接口；调用 chargeAccount() 完成实际扣账/入账；根据返回的 ChargeAccountResult 更新子流水状态、响应码、响应信息；通过 SubResultDetail.detail() 保存子交易处理结果 无直接返回值，通过更新传入对象返回处理结果

TaeSettleEngineComponent

方法
功能描述
 输入(Input) 内部操作 输出(Output)
TaeSettleEngineComponent SAGA模式记账入口，负责一次完整交易生命周期管理，包括流水登记、账户检查、远程记账、异常处理、冲正补偿 SettleEngineInput input，包含主交易信息(TaeAcctMaintradesRow)、子交易信息(TaeAcctSubtradesRow)、账户系统、交易金额、借贷方向等业务数据 初始化 autoReverseFlag 自动冲正标识；创建 TaeAcctMaintradesPo 主流水对象、List<TaeAcctSubtradesPo> 子流水集合、TaeAcctSubtradesAttachmentPo 扩展信息、TaeTranInfoPo 交易信息对象；调用 TaeSettleEngineUnit.preProcess() 完成交易幂等检查、防悬挂检查以及流水对象初始化；如果已存在交易结果直接返回；否则通过 TaeTransitIsolationUnit.getTransitIsolationFlag() 判断是否开启金额隔离；调用 TaeTradeUnit.createTeaAcctTrades() 提前登记交易流水；调用 TaeSettleEngineUnit.preCredCheck() 执行贷方账户检查；调用 chargeAccount() 完成借方下账和贷方入账；根据返回结果判断成功、失败、超时情况；成功时更新交易结果并释放金额隔离；失败时调用 TaeReversalUnit.accountReversal() 执行反向冲正 SettleEngineOutput，返回交易状态、响应码、响应信息、子交易明细

chargeAccount

方法
功能描述
 输入(Input) 内部操作 输出(Output)
chargeAccount 执行实际借贷账户处理，是SAGA记账核心方法 主流水 TaeAcctMaintradesPo；子流水集合 List<TaeAcctSubtradesPo>；附件信息；结果集合 resultDetailList；上下文参数 contextMapParam；金额隔离标识 transitIsolation 首先通过 dcFlag 筛选借方流水(D)，循环调用 singleChargeAccount() 执行扣账；根据返回结果更新子流水状态；如果出现超时调用 TaeVerifyService.chargeAccountVerify() 查询真实结果；借方成功后继续处理贷方流水©；根据 transitIsolation 判断是否开启金额隔离参数；执行贷方入账；统计成功数量；根据多笔交易结果调用 checkRedLine() 判断整体状态 ChargeAccountResult，返回整体成功、失败、部分成功状态

singleChargeAccount

方法
功能描述
 输入(Input) 内部操作 输出(Output)
singleChargeAccount 单笔账户记账调用入口，屏蔽不同账户系统实现差异 主流水、子流水、附件信息、交易参数 根据 taeAcctSubtradesPo.getAcctSystem() 获取账户系统；调用 TaeIntegrationFactory.sageInstance() 获取对应账户实现；调用账户系统 chargeAccount() 完成扣账或入账 ChargeAccountResult

checkRedLine

方法
功能描述
 输入(Input) 内部操作 输出(Output)
checkRedLine 判断多笔贷方交易最终状态，处理部分成功场景 List<ChargeAccountResult> 多笔记账结果；total 总数量 统计成功数量 successCount；如果成功数量为0，返回失败；如果成功数量小于总数量，返回部分成功；全部成功返回成功 ChargeAccountResult
